# Supplier Performance and Spend Analysis

**Question:** Which suppliers deliver reliably, and where does our purchasing spend go?

**Tools:** Python (pandas, Matplotlib), Google Colab

## Files
- `data/raw/`: original purchase orders and supplier master CSVs
- `data/clean/`: cleaned versions of both files
- `notebooks/`: Colab notebook with the cleaning, merge and analysis
- `images/`: supplier performance chart

## Note
The notebook reads its data from a Google Drive folder. To rerun it, upload the files from `data/raw/` and change the file paths.
